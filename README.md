# Player Transfer System

A Java-based project simulating a Cricket club player transfer system using object-oriented programming. JavaFX provides a user-friendly graphical interface, and a server-client network handles transfer requests.

## Features
- Club login system.
- Player buying and selling functionality.
- Server-client networking for real-time communication.

## Technologies
- **Java**: Core logic.
- **JavaFX**: GUI.
- **Networking**: Server-client communication.

## How to Run
1. Clone this repository.
2. Navigate to the `src` folder.
3. Run the server application.
4. Run `MainApplication.java` for the GUI.
